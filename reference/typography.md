# Typography System（字号与层级规范）

管的是「字号该多大、层级怎么拉开、行距怎么配」。字体选什么见 `fonts.md`，风格方向见 `slides_categories/`。本表数值是本 skill 的设计预设，不是行业标准；与业界主流指南的关系见文末参照。

## 基准与换算

- PPTD 画布 16:9 推荐 `960×540`，规格定义 **1px = 1pt**（`fontSize: 18` 即 PPTX 里 18pt）。因此本文所有数值 = PowerPoint pt 值，可直接使用。
- QA 导出 PNG 为 1280×720（×1.333），目检时注意分辨率差异。
- 4:3（720×540）画布宽度收窄 25%，长标题先缩写、换行或调布局，最后才考虑降字号。

## 字号层级表（960×540 基准）

| 角色 | 推荐值域 | 起步默认 | 说明 |
|---|---|---|---|
| 封面主标题 | 44–64 | 52 | 全 deck 常规文本中最大（数据大数字等展示性数字除外），一页只有一个 |
| 章节页标题 | 40–56 | 44 | chapter 页视觉主角，可配大色块 |
| 页标题 | 28–36 | 30 | 内容页顶部，全 deck 统一同档 |
| 小节/卡片标题 | 20–24 | 22 | 与正文的层级差不足 1.25× 时，必须配 bold 或主题色 |
| 正文 | 16–20 | 18 | 默认值（见 pptd.md 默认表） |
| 辅助注释/来源/页脚 | 12–14 | 13 | 硬下限 12，仅限页码、法律文本等不必在投屏下细读的内容 |
| 数据大数字 | 40–72 | 48 | 数据卡主角，配 14–16 标签 |
| 图表轴标/图例 | 14–16 | 14 | 投屏下 12 几乎不可读，不低于 14 |

**场景分流（决定正文档位，写 deck 前先判定）**：

- **投屏演示**（会议室/教室大屏，远距观看）：正文 ≥20，大教室/礼堂 ≥24，页标题相应上探。
- **阅读型 deck / slidedoc**（发给人在电脑/手机上看）：正文 16–18 可接受。
- 面向投资人的 pitch deck 常用正文 24 起。

触及下限后的处理顺序：**删减/提炼内容 → 重排或分栏 → 拆页 → 最后才有限降字**；降到下限后不得再缩，回退到前面的手段。

## 层级对比原则

1. **相邻层级建议 ≥1.25×**；字号差不足时（如卡片标题 22 对正文 18），**必须**以字重（bold）或颜色差异补足层级，否则两档混同。
2. **内容区 ≤3 档字号**（页标题与页脚注释不计入）；第 4 档出现先怀疑信息过载。
3. **层级优先用字重与颜色补足**：同档强调用 bold / 主题色，不要为强调再加一档字号。
4. **全 deck 一致**：同类角色全篇同值——页标题要么全 30 要么全 32，逐页漂移是最常见的 AI 生成破绽。
5. **字重纪律**：标题类 bold、正文 regular、注释 regular——不要出现正文加粗而标题细体的倒挂。

## 行高与间距配套

| 场景 | lineHeight | 说明 |
|---|---|---|
| 标题（≤36） | 1.2–1.3 | 紧凑有力 |
| 大数字 | 1.0–1.1 | 数字块不换行为前提 |
| 正文（投屏演示） | 1.3–1.4 | 演示幻灯片不是网页长文，1.5+ 会快速吃满 540pt 高度 |
| 正文（阅读型 deck） | 1.4–1.5 | 近距阅读可稍松 |
| 注释 | 1.3–1.4 | |

段间距用 `marginTop`（8–24），不要用空行凑间距。

**容量预算**（防溢出，AI 生成必查）：540pt 高扣除安全边距（上下各约 40）与页标题区（约 60），正文可用约 380–400pt。18pt 正文按行高 1.35 约占 24pt/行，单文本框建议 ≤10 行；中文单行按文本框宽度 ÷（fontSize×1.05）估字数。超预算走上面的回退顺序。

## theme 配合纪律（改字号的正确姿势）

1. **层级改在 theme.textStyles**，不要逐元素硬编码：建 `title`/`subtitle`/`body`/`caption` 至少四档，页面里用 `$ref` 引用。全局调字号 = 改 theme 一处。
2. 元素级 `fontSize` 只用于**例外**（某页数据大数字、特殊强调）。例外超过一页三处，说明该扩 theme 档位。
3. 已有 deck 调整层级时，先 grep `fontSize` 找出硬编码点，归并到 theme 再调。

## 特殊场景

- **数据卡**：大数字（44+）+ 小标签（14–16）+ 来源注释（12–13）三层，禁止三层数值接近。单位符号（%、万、¥）用富文本 `<span style="font-size:...">` 缩至数字的 1/2–1/3，不要和数字同字号。
- **表格**：表头与表体同字号（16–18）靠字重与底色区分，不靠字号。
- **引文**：20–24 斜体或宋体，署名 14。
- **图表**：轴标/图例 ≥14；标签拥挤时先减刻度、简化标签、拆分图表，不要缩字硬塞。
