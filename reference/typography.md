# Typography System（字号与层级规范）

管的是「字号该多大、层级怎么拉开、行距怎么配」。字体选什么见 `fonts.md`，风格方向见 `slides_categories/`。

## 基准与换算

- PPTD 画布 16:9 推荐 `960×540`，规格定义 **1px = 1pt**（`fontSize: 18` 即 PPTX 里 18pt）。因此本文所有数值 = PowerPoint pt 值，可直接使用。
- QA 导出 PNG 为 1280×720（×1.333），目检时注意分辨率差异。
- 4:3（720×540）画布宽度收窄 25%，长标题优先降字号而不是截断。

## 字号层级表（960×540 基准）

| 角色 | 推荐值域 | 起步默认 | 说明 |
|---|---|---|---|
| 封面主标题 | 44–64 | 52 | 全 deck 最大字号，一页只有一个 |
| 章节页标题 | 40–56 | 44 | chapter 页视觉主角，可配大色块 |
| 页标题 | 28–36 | 30 | 内容页顶部，全 deck 统一同档 |
| 小节/卡片标题 | 20–24 | 20 | 与正文拉开且不抢页标题 |
| 正文 | 16–20 | 18 | 默认值（见 pptd.md 默认表）；投屏为主的上探 20 |
| 辅助注释/来源/页脚 | 12–14 | 13 | 硬下限 12，再小失去可读性 |
| 数据大数字 | 40–72 | 48 | 数据卡主角，配 14–16 标签 |
| 图表轴标/图例 | 12–14 | 13 | 与注释同档 |

**硬下限**：正文 16（会议投屏）/ 24（大教室、礼堂等远距观看，标题相应上探 60+）；面向投资人的 pitch deck 建议正文不低于 20、常用 24+。低于下限一律先删内容再降字号。

## 层级对比原则

1. **相邻层级 ≥1.25×**，低于此值两档字混在一起（如 30 与 26 分不出主次）；跨级（标题 vs 注释）保持 2× 以上。
2. **一页 ≤3 档字号**（如 30/18/13），第 4 档出现先怀疑信息过载。
3. **层级优先用字重与颜色补足**：同档强调用 bold / 主题色，不要为强调再加一档字号。
4. **全 deck 一致**：同类角色全篇同值——页标题要么全 30 要么全 32，逐页漂移是最常见的 AI 生成破绽。

## 行高与间距配套

| 场景 | lineHeight | 说明 |
|---|---|---|
| 标题（≤36） | 1.2–1.3 | 紧凑有力 |
| 大数字 | 1.0–1.1 | 数字块不换行为前提 |
| 正文 | 1.5–1.6 | 中文正文低于 1.4 明显拥挤 |
| 注释 | 1.4 | |

段间距用 `marginTop`（8–24），不要用空行凑间距。

## theme 配合纪律（改字号的正确姿势）

1. **层级改在 theme.textStyles**，不要逐元素硬编码：建 `title`/`subtitle`/`body`/`caption` 至少四档，页面里用 `$ref` 引用。全局调字号 = 改 theme 一处。
2. 元素级 `fontSize` 只用于**例外**（某页数据大数字、特殊强调）。例外超过一页三处，说明该扩 theme 档位。
3. 已有 deck 调整层级时，先 grep `fontSize` 找出硬编码点，归并到 theme 再调。

## 特殊场景

- **数据卡**：大数字（44+）+ 小标签（14–16）+ 来源注释（12）三层，禁止三层数值接近。
- **表格**：表头与表体同字号（16–18）靠字重与底色区分，不靠字号。
- **引文**：20–24 斜体或宋体，署名 14。
- **图表内文字**：以 PowerPoint 实际渲染为准，轴标 12–14，数据标签 12–14，超出会挤压图形区。
